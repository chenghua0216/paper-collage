# 剪紙拼貼 · Paper Collage

模擬剪紙拼貼的藝術創作 Web App，走 Matisse 剪紙那種俐落有機形狀的乾淨風格。

## 功能（MVP）

- **形狀庫**：12 種剪紙形狀（有機形、葉片、海星、海藻、波浪、拱形、花瓣、幾何形…），點一下即加入畫布。
- **配色盤**：Matisse 風格的大膽飽和色，選色後新增或幫選取的紙片重新上色。
- **紙感質感**：每片紙帶柔和投影，模擬剪紙貼在底紙上微微浮起的立體感。
- **自由編輯**：拖曳移動、四角縮放、頂端把手旋轉。
- **圖層**：移到最上／最下、上一層／下一層。
- **畫布底色**：多種紙張底色可切換。
- **匯出**：一鍵輸出 2× 解析度 PNG。
- 快捷鍵：`Delete` / `Backspace` 刪除選取的紙片。

## 技術

React + Vite + [Konva](https://konvajs.org/)（react-konva）。拼貼本質是「管理很多可拖曳、可變形的圖層」，Konva 的 canvas 2D 圖層模型很適合。

## 開發

```bash
npm install
npm run dev      # 開發伺服器 http://localhost:5173
npm run build    # 打包到 dist/
npm run preview  # 預覽打包結果
```

## 之後可以再做

- **撕邊質感**：不規則撕裂路徑 + 白色紙芯毛邊（切換剪邊／撕邊）。
- **紙張材質貼圖**：牛皮紙、宣紙、報紙等紋理填充。
- **自由手繪裁切**：用畫筆或多邊形自訂形狀。
- **存檔／讀取**：把作品存成 JSON，之後可繼續編輯。
- **手機版**：觸控體驗優化，或包成 React Native App。
